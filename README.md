# IT Pulse — IT Incident Management Simulator

## Overview
IT Pulse is a Python-based application that simulates an IT service desk workflow. It helps users record incidents, assign priorities, track resolution progress, and monitor operational trends through a dashboard.

## Features
- **Incident logging:** Record incident titles, descriptions, categories, severity, and ownership.
- **Incident tracking:** View, search, and filter incidents by status and severity.
- **Operational dashboard:** Monitor incident volume, active critical incidents, and status distribution.
- **Incident updates:** Update ticket status, assignee, and resolution time.
- **CSV export:** Export incident records for further analysis and reporting.
- **Escalation guide:** Review illustrative priority-handling rules and incident lifecycle steps.

## Technology Stack
- Python
- Streamlit
- Pandas
- Plotly
- CSV-based local storage

## How to Run
1. Install Python 3.10 or later.
2. Install dependencies using `python -m pip install -r requirements.txt`.
3. Start the app using `python -m streamlit run app.py`.
4. Open the local URL displayed in the terminal.

## Project Scope
This is a portfolio demonstration using simulated incident records and local CSV storage. It is not connected to a production ticketing system.

## Skills Demonstrated
Incident tracking, prioritization, workflow documentation, operational reporting, data visualization, and basic application development.
